## 🏃 Getting Started

To explore these SwiftUI UI flows:

1.  **Clone this repository:**
    ```bash
    git clone https://github.com/ZUXXSU/Rimashaar-assignment-UI.git
    ```
2.  **Open in Xcode:**
    Navigate to the project directory and open the `.xcodeproj` file.
3.  **Use Xcode Previews:**
    The UI components can be viewed and interacted with instantly using **Xcode Previews**, demonstrating the responsive design across device sizes.
4.  **Build and Run:**
    Run the app on a simulator (Cmd+R) to see the full animated flow.
